Simulation Engine
────────────────────────────────────────────────────────────────────────────────
  ✅ Forward-time population genetics simulation
  ✅ Explicit IBD segment tracking with founder labels
  ✅ P. falciparum 14-chromosome genome (realistic lengths)
  ✅ Poisson-distributed recombination (~7.4×10⁻⁷ per bp)
  ✅ Wright-Fisher population model
  ✅ Optional self-fertilization
  ✅ Multi-population support with migration matrix
  ✅ Demographic events (bottlenecks, size changes)

IBD Detection Methods
────────────────────────────────────────────────────────────────────────────────
  ✅ Threshold-based caller (sliding window IBS)
  ✅ HMM-based caller (hmmIBD-style with forward-backward)
  ✅ Window-based caller (isoRelate-style overlapping windows)
  ✅ Extensible framework for custom methods

Evaluation Framework

  ✅ Sensitivity, precision, F1 scores
  ✅ Per-base comparison of called vs true IBD

  ✅ Export to CSV for further analysis

MINIMAL USAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

from simulation_runner import SimulationRunner
import numpy as np

# Setup
runner = SimulationRunner()
runner.setup_single_population(pop_size=100)

# Simulate
individuals = runner.run_simulation(num_generations=20)
sampled = list(np.random.choice(individuals, size=30, replace=False))

# Analyze
true_ibd = runner.compute_ground_truth_ibd(sampled, min_length=100000)
genotypes = runner.generate_genotype_data(sampled, snps_per_chrom=1000)
called_ibd = runner.call_ibd_all_methods(genotypes, sampled)

# Evaluate
evaluation = runner.evaluate_methods()
print(evaluation.groupby('method')[['sensitivity', 'precision']].mean())

# Save
runner.save_results()

Key Design Principles
────────────────────────────────────────────────────────────────────────────────
  • Explicit IBD tracking: Every segment knows its founder
  • Forward-time: Natural demographic events
  • Modular: Clean separation of concerns
  • Extensible: Easy to add new features
  • Validated: Ground truth for method evaluation

Data Structures
────────────────────────────────────────────────────────────────────────────────
  Segment      → (start, end, founder_id, generation)
  Chromosome   → List[Segment] (contiguous, non-overlapping)
  Individual   → 14 × (maternal, paternal) chromosome pairs
  Population   → List[Individual] + demographic events
  Simulator    → Multiple populations + migration

Algorithms
────────────────────────────────────────────────────────────────────────────────
  Recombination: Poisson breakpoints → alternate parents → merge segments
  HMM Calling:   Forward-backward algorithm in log space
  Evaluation:    Per-base comparison of segment overlaps
